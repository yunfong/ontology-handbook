8.2 Agent 上下文层与本体化记忆

给模型一份有类型、有约束、可追溯的语义

这一类的共同判断是：Agent 的失败主要不是模型不行，而是缺一份有类型、有约束、可追溯的企业语义。但落到实现上，十个项目里只有三个是真形式本体（OntoGPT、CortexDB、OntoBricks），其余是「带类型的上下文」或「记忆」。混淆这两者，会高估它们的推理能力、低估它们的工程价值。

判据：问它「能不能拒绝一条不合法的写入」。能，是本体；不能，是上下文。

Semantica

B
semantica-agi/semantica
★ 14,3422025-06-25PythonMIT
图原生的上下文与「可问责 AI」基础设施，topics 覆盖 agent-memory、context-graphs、ai-governance。README 自称是昂贵企业平台的替代品。
何时采纳比较「上下文层」这一品类时，作为高星参照。

Utopia

B
deeplethe/utopia
★ 8,6372026-08-07RustApache-2.0
自称「首个开源企业世界模型」，Rust 实现，带双时态（事实何时为真 / 系统何时得知）与自家规则格式。有真公理，但 README 不提 OWL / RDF / SPARQL。
何时采纳需要「两个时钟」的时间模型参考时。

Jonex

B
yuezhiai/jonex
★ 1,5182026-07-19PythonNOASSERTION
多模态文档解析 + 本体驱动的知识引擎，对外叫 LLMWiki。定位是「把文档变成可问的知识」，本体在其中承担概念层。
何时采纳文档密集型场景的端到端参考。

EvoOntology

B
ruc-datalab/EvoOntology
★ 1,1022026-09-15PythonMIT
人大团队给编码 Agent 装的一层「自进化本体」，MCP 兼容。最值得看的是 gated versioning：同一份数据、同一个 Agent、同一份预算下对比 Parent 与 Candidate，通过才发布。
何时采纳设计「新版本本体怎么才算更好」的验收门时。

OntoGPT

A
monarch-initiative/ontogpt
★ 1,0802023-01-03Jupyter NotebookBSD-3-Clause
LLM 加本体约束的结构化抽取（SPIRES 路线），学术机构长期维护。本体在外部，项目负责把文本「接地」到既有术语上，而不是自己发明一套。
何时采纳要从文献/报告里抽出结构化事实并对齐既有词表时。

ClearAI DSH

B
Clearailhc/clearai-dsh
★ 6802026-09-12JavaScriptApache-2.0
本体优先的 Agent preset：状态从会话记录投影、判卷与执行分离、阈值预注册、被推翻的结论不删除。它把这些认识论纪律写进了 Agent 的运行方式，而不是文档里。
何时采纳想把「评测先行」变成 Agent 的硬约束时。

NVIDIA Auto Ontology

A
NVIDIA/auto-ontology
★ 6482026-04-27PythonApache-2.0
从数据反推语义图的框架，四步 Discover → Ground → Validate → Expose，强调确定性查询，对外暴露 MCP / CLI / API 三种入口。
何时采纳评估「从表结构自动生成语义层」的可行性时。

Carrel

B
FengZhenfei/carrel
★ 6432026-09-28PythonMIT
Ontology-Augmented Generation：自托管知识库，解析、索引、检索，图谱是可选增强。作者自述 Agent Loop 尚未实现，本体是未完成部分——这一点比它的宣传更值得注意。
何时采纳了解 OAG 这一提法的实际完成度时。

CortexDB

B
liliang-cn/cortexdb
★ 4732025-08-07GoMIT
单文件 SQLite 装下 Agent 记忆、知识图与本体约束：RDF 1.2 / SPARQL / OWL 2 RL / SHACL，通 W3C 测试套件，并带一条 exactly-once 的变更流。零部署。
何时采纳边缘侧、单机部署、又想有约束能力时。

OntoBricks

A
databrickslabs/ontobricks
★ 4552026-04-07PythonNOASSERTION
把 Unity Catalog 的表变成知识图：OWL 2 RL、SWRL、R2RML、SHACL 全部编译成 Spark SQL 执行，带 DRAFT→IN-REVIEW→PUBLISHED 与单编辑者租约。是这一类里唯一同时具备标准本体栈、映射层、物化与治理的项目。
何时采纳想知道「湖仓上的本体工程」长什么样时。
